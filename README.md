# optimal-path-finder(최적 경로 서비스 프로그램 개발)

교량(점검 대상) 목록을 기반으로 **일자별 최적 점검 경로**를 계산하고, 지도에서 경로를 시각화하는 내부용 도구입니다.  
(카카오 지도/길찾기 API 사용)

---

## 1) 빠른 시작(필수)

1. **Releases**에서 최신 ZIP 다운로드 후 압축 해제
2. `config.json`에 **카카오 API 키** 입력
3. `main_program.exe` 실행
4. 브라우저에서 접속: http://127.0.0.1:8000

> 실행 중 콘솔/창을 닫으면 서버가 종료될 수 있습니다.

---

## 2) 설정(config.json)

`config.json` 예시:

```json
{
  "KAKAO_REST_API_KEY": "여기에 입력",
  "KAKAO_JS_API_KEY": "여기에 입력"
}
```

### 카카오 JavaScript 키(Web 플랫폼) 등록(중요)
카카오 지도 표시를 위해 **Web 플랫폼 도메인 등록이 필요**합니다.

- Kakao Developers → 내 애플리케이션 → **플랫폼** → **Web**
- 사이트 도메인에 아래 주소를 등록:
  - `http://127.0.0.1:8000`

등록 후에는 프로그램을 **재실행**하세요.

---

## 3) 사용 방법(화면 기준)

- 좌측: 지도(일자별 경로 라인/마커 표시)
- 우측: **최적화 결과**(Day별 일정, 도착/완료 시각, 이동/점검 시간 요약)

기본 흐름:
1) (필요 시) 대상/옵션 선택  
2) 최적화 실행  
3) Day 1 ~ Day N 일정과 경로 확인  
4) “처음으로”로 초기화 후 재실행 가능

---

## 4) 데이터(교량 DB) 업데이트

교량 목록은 아래 엑셀 파일을 수정하여 갱신합니다.

- 경로: `main_program_internal/data/bridge_database.xlsx`

권장:
- 위도/경도, 교량명, 주소 등 **필수 컬럼 형식**을 유지
- 수정 후 프로그램을 **재실행**(또는 새로고침)하여 반영 여부 확인

---

## 5) 폴더 구조(요약)

- `main_program.exe` : 실행 파일
- `main_program_internal/` : 실행에 필요한 리소스/데이터
- `data/` : (프로젝트 구성에 따라) 입력 데이터/캐시 저장 위치
- `templates/`, `static/` : 웹 UI 리소스

---

## 6) 자주 발생하는 문제(FAQ)

### Q1. 지도가 안 뜨거나 인증 오류가 납니다.
- `KAKAO_JS_API_KEY`가 올바른지 확인
- Kakao Developers에서 **Web 플랫폼 도메인(`http://127.0.0.1:8000`) 등록** 확인
- 등록/수정 후 **재실행**

### Q2. 실행했는데 접속이 안 됩니다.
- 브라우저에서 `http://127.0.0.1:8000` 직접 접속
- 8000 포트가 이미 사용 중이면(다른 서버 등) 종료 후 재시도

### Q3. 경로 계산이 느립니다.
- 대상 건수/일정 일수가 많으면 시간이 소요될 수 있습니다.
- 네트워크 상태(카카오 API 호출) 영향을 받습니다.
